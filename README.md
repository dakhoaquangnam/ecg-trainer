# Luyện đọc ECG — theo Marriott

Web app học đọc điện tim theo sách Marriott's Practical Electrocardiography (13th ed):
21 chương + luyện ca PTB-XL có đáp án + AI gia sư giải thích + lưu tiến độ.

Bản build (Vite + React + TS) nằm ở nhánh `main`, phục vụ qua GitHub Pages.
Mã nguồn: xem thư mục dự án trên máy phát triển.
